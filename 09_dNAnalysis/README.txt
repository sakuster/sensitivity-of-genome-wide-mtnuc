During revisions, a new analysis was added to correlate mitonuclear LD to the number of non-synonymous substitutions in a gene. Those scripts are included here. 

The 'non-synonymous-analysis' scripts will create an output file that determines substitutions (whether they are synonymous or non-synonymous) associated with each gene. 

The 'non-syn-stat-analysis' calculates and outputs stats for each population's analysis.

The 'non-syn-fig-maker' will make the figures seen in the manuscript for each population's non-synonymous analysis.
